# List Standard `dicomtk.server` RBAC Roles

List Standard `dicomtk.server` RBAC Roles

## Usage

``` r
server_roles()
```

## Value

Character vector of the 8 standard server roles.

## Examples

``` r
server_roles()
#> [1] "pi"            "coordinator"   "annotator"     "auditor"      
#> [5] "admin"         "site_admin"    "honest_broker" "dpo"          
```
