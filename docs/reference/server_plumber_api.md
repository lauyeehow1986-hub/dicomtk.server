# Build a `plumber` REST Router for `dicomtk.server`

Build a `plumber` REST Router for `dicomtk.server`

## Usage

``` r
server_plumber_api(ctx)
```

## Arguments

- ctx:

  A `"dicom_server_context"` object.

## Value

A [`plumber::Plumber`](https://www.rplumber.io/reference/Plumber.html)
router instance.
